# EG Backend Theme

Odoo 19.0 Community addons that restyle the backend web client with a component language inspired by
PrimeNG and shadcn/ui, while keeping Odoo's layout: navbar, breadcrumbs, search facets, statusbar and chatter
stay where users expect them.

| Addon | Summary |
| --- | --- |
| `eg_backend_theme` | Theme tokens, restyled native components, per-user and per-company appearance (style, accent, surface, light/dark, density, navbar) and a searchable app launcher. |
| `eg_backend_theme_mail` | Chatter, composer, activities and tracking values for the theme. Installed automatically with `mail`. |
| `eg_ops_panel` | Optional operations dashboard (quotations, confirmed orders, deliveries, overdue activities). |
